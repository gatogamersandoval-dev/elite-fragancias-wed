# Cómo editar ELITE FRAGANCIAS

Esta carpeta contiene la página web de ELITE FRAGANCIAS. Para verla localmente, abre el archivo `index.html` en el navegador.

## Cambiar fotografías

Las imágenes están dentro de la carpeta `assets`. Puedes reemplazar una imagen conservando exactamente el mismo nombre y formato, o editar el archivo `index.html` para cambiar la ruta que aparece en `src="/assets/nombre-de-la-imagen"`.

Las fotografías de los productos actuales son `pure-xs-men.png` y `santal-33.png`. El logo completo es `elite-logo-full.jpg` y el logo pequeño es `elite-logo-mark.jpg`.

## Cambiar textos

Abre `index.html` con un editor de texto. Usa la búsqueda del editor para localizar el nombre, descripción, teléfono, correo o texto que quieras cambiar. No borres las etiquetas que comienzan con `<` y terminan con `>`.

## Cambiar enlaces

Los enlaces de Instagram, TikTok y WhatsApp están dentro de `index.html`. Puedes reemplazar las direcciones que empiezan por `https://` conservando las comillas.

## Importante

La carpeta descargada es una copia de la página. Cambiarla en tu computador no cambia automáticamente una página publicada en internet. Cuando tengas cambios listos, puedes enviármelos para revisarlos o subir esta carpeta a un servicio de hosting como Netlify, GitHub Pages o Cloudflare Pages.

La publicación definitiva queda pendiente hasta que tú decidas hacerlo.
